# FaB Binder

Organizador da minha coleção de **Flesh and Blood**: um app web para PC e celular que mostra quais cartas de cada set eu tenho e quais ainda faltam para completar os playsets.

Os dados das cartas vêm do [the-fab-cube/flesh-and-blood-cards](https://github.com/the-fab-cube/flesh-and-blood-cards).
